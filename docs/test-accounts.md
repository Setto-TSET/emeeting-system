# บัญชีทดสอบ

บัญชีทั้งหมดมาจาก `src/data/index.ts` และถูกสร้างใน DB ด้วย `npm run seed` ฝั่ง backend
เดิมแสดงเป็นปุ่มกรอกอีเมลอัตโนมัติบนหน้า login — ย้ายมาไว้ที่นี่เพราะหน้า login ของระบบจริง
ไม่ควรเปิดเผยรายชื่อผู้ใช้และบทบาทให้ใครก็ได้เห็น

**รหัสผ่าน:** ทุกบัญชีใช้รหัสเดียวกัน คือค่า `SEED_PASSWORD` ที่ผู้ดูแลตั้งตอนรัน seed
รหัสผ่านไม่ได้เก็บไว้ในไฟล์นี้หรือใน repo — ขอจากผู้ดูแลระบบ
ถ้าต้องการเปลี่ยนรหัสของทุกบัญชี: ตั้ง `SEED_PASSWORD` ใหม่แล้วรัน `npm run reset-password` ใน `backend/`

> บัญชีเหล่านี้มีไว้ทดสอบเท่านั้น ก่อนนำระบบไปใช้งานจริงต้องลบหรือปิดทุกบัญชี
> แล้วสร้างบัญชีจริงของหน่วยงานแทน

**ช่องล็อกอินรับได้ 3 แบบ:** ชื่อบทบาท (เช่น `secretary`) จะเข้าบัญชีแรกของบทบาทนั้นตามตารางนี้
(admin, executive → ประเสริฐ, secretary → มาลี, staff → สมชาย, external → ที่ปรึกษา, room → ห้อง 801),

แขก (บุคคลภายนอกที่ไม่มีบัญชี) ไม่ใช้บัญชีในตารางนี้ — เข้าผ่านลิงก์เชิญที่ผู้จัดการประชุม
สร้างจากหน้ารายละเอียดการประชุม (`/join/<token>`) — ลิงก์เดียวต่อการประชุม ใช้ได้หลายคนจนกว่าผู้จัดจะสร้างลิงก์ใหม่หรือปิดรับบุคคลภายนอก
